바로조 개인정보처리방침

시행일 2026-11-07 · 적용 대상: 바로조(Barrojo) Google OAuth 앱

1. 누가 쓰나

바로조는 운영자 본인 한 사람이 자기 맥북에서 쓰는 개인용 도구다. 다른 사람에게 서비스를 제공하지 않는다.

2. 접근하는 Google 데이터

  • calendar.calendarlist.readonly — 캘린더 목록 읽기
  • calendar.events.readonly — 일정 읽기(전날부터 30일 뒤까지)
  • calendar.app.created — 바로조가 만든 보조 캘린더에만 일정 쓰기·고치기·지우기

사람이 쓰는 기본 캘린더의 일정은 만들거나 고치지 않는다.

3. 어디에 쓰나

운영자의 현황 표·브리핑·대화 답변에 일정을 보여 주고, 노션 작업 일정을 바로조 보조 캘린더로 옮기는 데만 쓴다. 광고·판매·사람 평가·모델 학습용 데이터 제공에는 쓰지 않는다.

4. 어디에 저장하나

  • 일정 색인과 동의 토큰은 운영자 맥북의 로컬 파일(~/.barrojo/, 토큰은 소유자만 읽기 가능)에만 저장한다.
  • 모바일 앱은 운영자의 개인 네트워크로 맥북에 접속해 현황을 받아 화면에 보여 줄 뿐, 별도 서버에 일정을 보관하지 않는다.

5. 다른 곳으로 가는 데이터

브리핑과 대화 답변을 만들 때, 7일 안 일정의 제목·시각·장소 요약이 운영자 본인 계정으로 쓰는 Anthropic Claude 모델에 전달된다. 그 응답을 만드는 데만 쓰며, 그 밖의 제3자에게 팔거나 넘기지 않는다. 바로조의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따른다.

6. 보관과 삭제

일정 색인은 수집할 때마다 새로 맞춰지며, 원본은 Google 캘린더다. 접근을 끊으려면 Google 계정 → 서드 파티 앱 액세스에서 '바로조'를 삭제하면 된다. 그 뒤 맥북의 ~/.barrojo/google.json 과 색인을 지우면 로컬 사본도 남지 않는다.

바로조 홈

Summary: Barrojo is a single-user tool. It reads the operator's Google Calendar and writes only to calendars it created. Data stays on the operator's MacBook; summaries of upcoming events are sent to the operator's own Anthropic Claude account only to generate briefings and answers. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
